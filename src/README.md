# 🌾 Crop Recommendation System

## 📌 Problem Statement
Farmers often struggle to choose the right crop for their land due to soil nutrients, weather, rainfall, and pH conditions. Wrong choices can cause low yield and financial loss.

This project builds an **AI-based Crop Recommendation System** using Python and Machine Learning to recommend the best crop.

---

## ⚙️ Features
- Takes inputs: N, P, K, temperature, humidity, pH, rainfall
- Suggests the most suitable crop
- Provides top-3 crop recommendations with probability
- Streamlit web app for farmers
- Re-trainable model (`train.py`) with Kaggle dataset

---

## 🛠️ Tech Stack
- Python, Pandas, NumPy, Scikit-learn
- Joblib (model saving)
- Jupyter Notebook (EDA)
- Streamlit (Web UI)
